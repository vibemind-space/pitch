Agent spaces for your business.

The problem

An agent with every tool is an agent you cannot reason about
  • A language model on its own does nothing. Everything that turns its output into work is the harness: routing, execution, memory and transport.
  • For two years the harness is where the real engineering went, and almost none of it has been public.
  • Choosing among twelve tools is tractable for an agent. Choosing among five hundred is not.
  • A model-based decision is an answer you have to trust. A rule you can read is one you can verify.

Our answer

Spaces bound what can happen. Agents do the work inside them.
  • A space is a bounded working context with its own agents, tools and vocabulary: sales, marketing, video, business data.
  • Each space works on its own or as part of Vibemind.
  • Vibemind is an open-source operating system for a fleet of AI agents. The umbrella repository is public under the MIT licence.
  • Every space carries a label (live, in progress or research) and says whether its code is open source.

How it works

Intent → Brain → agents → check → memory
  • Step 1You type an intent or send it from a messaging channel. Voice is designed as a third entry point and is not working today.
  • Step 2The Brain matches it against a registry of 119 capabilities, by regular expression first. A hit is free, instant and explainable.
  • Step 3Without a hit, a model answers directly or plans the steps. The semantic fallback in between is not working yet.
  • Step 4Agents in the OpenFang runtime carry out the steps with the tools they are bound to. A follow-up loop checks the result before delivery.
  • Step 5The executed plan is logged. Decisions go to one memory, your material lives in another.

The stack

A harness you can read
  • Routing: the Brain. Its behaviour is configuration you can read, not something that emerges from a prompt.
  • Execution: OpenFang, a Rust agent runtime with 43 agents. Most run as Claude Code subprocesses with scoped tools and a timeout.
  • Tools: 50 in-house MCP servers with 798 tools, counted from the code on 27 October 2026.
  • Channels and models: Telegram and WhatsApp are configured. The runtime has adapters for 42 model providers; in practice most agents use one hosted Claude model.
  • Self-hosting is the point of the project. It is not a one-command install today.

What we verified

Runtime checks as of 27 October 2026, space labels as of 11 November 2026
  • Five spaces run on our own server. Marketing and Video still generate on a workstation.
  • The agent task chain ran end to end: order, agent, check, delivery.
  • Regex routing with ground-truth checks against the live database works.
  • A Telegram message to the bot was answered end to end in under 30 seconds.
  • Not running: the Brain's request service is scaled down for now. Voice, scheduling and the coding engine are untested.

Open source

Stated per component, not as one label
  • vibemind-os, the umbrella repository, has been public under MIT since 1 September 2026.
  • The stack is assembled from components under several licences: the OpenFang runtime is Apache-2.0 or MIT, several libraries are MIT, a few components are AGPL-3.0.
  • Some components carry no licence file yet, one brain component is licensed for non-commercial use only, and one video component is private.
  • The licensing page lists every component with its licence.
